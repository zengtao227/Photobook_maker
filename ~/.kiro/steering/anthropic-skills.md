## 核心 Skills 参考

### Skill: 第一性原理思考
**来源**: Anthropic Skills - First Principles Thinking

**应用场景**：
- 分析复杂问题
- 设计系统架构
- 做技术决策

**核心原则**：
1. 识别问题的根本原因（不是表面症状）
2. 分解到最基本的真理
3. 从基本原理重新构建解决方案
4. 避免基于类比或惯例的思考

### Skill: 最小化原则
**来源**: Anthropic Skills - Minimalism in Code

**应用场景**：
- 编写新代码
- 重构现有代码
- 评估解决方案

**核心原则**：
1. 最好的代码是没有代码
2. 次好的是更少的代码
3. 优先删除而不是添加
4. 简单优于复杂

### Skill: 渐进式开发
**来源**: Anthropic Skills - Incremental Development

**应用场景**：
- 实现新功能
- 重构大型系统
- 修复复杂 bug

**核心原则**：
1. 小步快跑
2. 每一步都可验证
3. 保持系统始终可工作
4. 及时获得反馈

### Skill: 防御性编程
**来源**: Anthropic Skills - Defensive Programming

**应用场景**：
- 处理外部输入
- 调用第三方 API
- 处理边界条件

**核心原则**：
1. 验证所有输入
2. 处理所有错误情况
3. 提供清晰的错误信息
4. 优雅降级

### Skill: 代码可读性
**来源**: Anthropic Skills - Code Readability

**应用场景**：
- 编写新代码
- 代码审查
- 重构

**核心原则**：
1. 代码是写给人看的
2. 命名要清晰表达意图
3. 函数要短小精悍
4. 注释解释"为什么"而不是"是什么"

### Skill: 测试驱动开发
**来源**: Anthropic Skills - Test-Driven Development

**应用场景**：
- 实现新功能
- 修复 bug
- 重构代码

**核心原则**：
1. 先写测试
2. 写最少的代码让测试通过
3. 重构改进代码
4. 保持测试快速可靠

## 使用指南

### 自动应用流程

```
1. 分析用户需求
   ↓
2. 识别相关的 Skills
   ↓
3. 应用 Skills 的原则和模式
   ↓
4. 在回复中引用使用的 Skills
   ↓
5. 提供符合 Skills 标准的解决方案
```

### 引用格式

在回复中引用 Skills 时，使用以下格式：

```
## 应用的 Skills

### [Skill 名称]
- **来源**: Anthropic Skills - [具体 Skill]
- **应用**: [如何应用到当前问题]
- **结果**: [应用后的效果]
```
