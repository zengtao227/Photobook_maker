# PhotobookApp 用户指南 / User Guide

## 中文版

### 快速开始

#### 1. 创建新项目
- 启动应用后，点击"新建项目"卡片
- 输入项目名称（或使用默认名称）
- 点击"创建"开始编辑

#### 2. 切换语言
- 点击工具栏右上角的地球图标 🌐
- 选择"中文"或"English"
- 所有界面元素将立即更新
- 您的语言偏好会自动保存

#### 3. 导入照片
- 点击左侧"素材库"面板
- 点击"导入文件夹"按钮
- 选择包含照片的文件夹
- 照片将按月份自动分组

#### 4. 添加照片到页面
- 从素材库拖动照片到画布
- 照片会自动添加到当前页面
- 使用角落的手柄调整大小
- 拖动照片可移动位置

#### 5. 编辑照片
- **调整大小**: 拖动四个角的手柄
- **旋转**: 拖动顶部的旋转手柄
- **裁剪**: 双击照片进入裁剪模式
- **滤镜**: 右键点击照片，选择"滤镜"
- **删除**: 选中后按 Delete 键或右键选择"删除"

#### 6. 添加文字
- 点击工具栏的"文字"按钮
- 选择添加到左页或右页
- 双击文字进行编辑
- 在右侧面板调整字体、大小、对齐方式

#### 7. 添加贴纸
- 点击工具栏的"贴纸"按钮
- 浏览不同分类（收藏、家庭、天气、节日、季节、美食）
- 点击贴纸添加到当前页面
- 调整大小和位置

#### 8. 管理页面
- 使用底部的页面导航器切换页面
- 点击"新建跨页"添加新页面
- 对于骑马钉装订，页数必须是4的倍数

#### 9. 保存项目
- **手动保存**: 点击保存按钮或按 ⌘S
- **自动保存**: 每60秒自动保存一次
- **退出时保存**: 关闭项目或退出应用时自动保存

#### 10. 导出PDF
- 点击工具栏的"导出 PDF"按钮
- 选择导出预设（屏幕预览、家用打印、专业印刷）
- 配置分辨率、出血设置、印刷标记
- 点击"导出"生成PDF文件

### 高级功能

#### 图层管理
- **移到最前**: 右键 → 移到最前
- **前移一层**: 右键 → 前移一层
- **后移一层**: 右键 → 后移一层
- **移到最后**: 右键 → 移到最后

#### 装订方式
- **软皮装**: 胶装，适合大多数照片书
- **精装**: 硬壳封面，高档感
- **蝴蝶装**: 跨页可完全平摊180°
- **骑马钉**: 中间装订，页数必须是4的倍数

#### 印刷标记说明
- **裁切线**: 打印时用于指示裁剪位置的线条
- **套准标记**: 用于对齐多色印刷的参考标记
- **色条**: 用于检查颜色准确性的参考条
- **页面信息**: 包含页码、日期等元数据

#### 出血设置
出血是指印刷时在裁切线外额外添加的图像区域，防止裁切误差导致白边。专业印刷通常需要3mm出血。

### 项目管理

#### 打开项目文件夹
- 在项目浏览器中点击"项目文件夹"按钮
- 可以查看、备份或转移项目文件
- 项目文件位置: `~/Library/Application Support/PhotobookPro/Projects/`

#### 在Finder中显示项目
- 右键点击项目卡片
- 选择"在Finder中显示"
- 可以直接访问项目文件

#### 转移项目到其他电脑
1. 打开项目文件夹
2. 复制项目JSON文件（如 `project-abc123.json`）
3. 在另一台电脑上，粘贴到相同位置
4. 重启应用或刷新项目列表

### 键盘快捷键
- **⌘N**: 新建项目
- **⌘O**: 导入文件夹
- **⌘S**: 保存项目
- **⌘W**: 关闭项目
- **Delete**: 删除选中的图层
- **Fn+Delete**: 删除选中的图层（备用）

## English Version

### Quick Start

#### 1. Create New Project
- Click "New Project" card after launching
- Enter project name (or use default)
- Click "Create" to start editing

#### 2. Switch Language
- Click the globe icon 🌐 in the toolbar
- Select "中文" or "English"
- All UI elements will update immediately
- Your language preference is saved automatically

#### 3. Import Photos
- Click "Library" panel on the left
- Click "Import Folder" button
- Select folder containing photos
- Photos will be automatically grouped by month

#### 4. Add Photos to Pages
- Drag photos from library to canvas
- Photos will be added to current page
- Use corner handles to resize
- Drag photos to move

#### 5. Edit Photos
- **Resize**: Drag corner handles
- **Rotate**: Drag top rotation handle
- **Crop**: Double-click photo to enter crop mode
- **Filter**: Right-click photo, select "Filter"
- **Delete**: Select and press Delete key or right-click "Delete"

#### 6. Add Text
- Click "Text" button in toolbar
- Choose to add to left or right page
- Double-click text to edit
- Adjust font, size, alignment in right panel

#### 7. Add Stickers
- Click "Stickers" button in toolbar
- Browse categories (Favorites, Family, Weather, Holiday, Seasons, Food)
- Click sticker to add to current page
- Resize and reposition as needed

#### 8. Manage Pages
- Use page navigator at bottom to switch pages
- Click "Add Spreads" to add new pages
- For saddle stitch binding, page count must be multiple of 4

#### 9. Save Project
- **Manual Save**: Click save button or press ⌘S
- **Auto-Save**: Automatically saves every 60 seconds
- **Save on Exit**: Automatically saves when closing project or quitting app

#### 10. Export PDF
- Click "Export PDF" button in toolbar
- Choose export preset (Screen Preview, Home Print, Professional)
- Configure resolution, bleed settings, print marks
- Click "Export" to generate PDF file

### Advanced Features

#### Layer Management
- **Bring to Front**: Right-click → Bring to Front
- **Bring Forward**: Right-click → Bring Forward
- **Send Backward**: Right-click → Send Backward
- **Send to Back**: Right-click → Send to Back

#### Binding Types
- **Softcover**: Perfect binding, suitable for most photobooks
- **Hardcover**: Rigid cover, premium feel
- **Layflat**: Spreads open completely flat 180°
- **Saddle Stitch**: Stapled in middle, pages must be multiple of 4

#### Print Marks Explanation
- **Crop Marks**: Lines indicating where to crop when printing
- **Registration Marks**: Reference marks for aligning multi-color printing
- **Color Bars**: Reference bars for checking color accuracy
- **Page Info**: Metadata including page numbers and dates

#### Bleed Settings
Bleed is the extra image area beyond the trim line to prevent white edges from cutting errors. Professional printing typically requires 3mm bleed.

### Project Management

#### Open Projects Folder
- Click "Project Folder" button in project browser
- View, backup, or transfer project files
- Project location: `~/Library/Application Support/PhotobookPro/Projects/`

#### Show in Finder
- Right-click project card
- Select "Show in Finder"
- Direct access to project file

#### Transfer Projects to Another Computer
1. Open projects folder
2. Copy project JSON file (e.g., `project-abc123.json`)
3. On another computer, paste to same location
4. Restart app or refresh project list

### Keyboard Shortcuts
- **⌘N**: New Project
- **⌘O**: Import Folder
- **⌘S**: Save Project
- **⌘W**: Close Project
- **Delete**: Delete selected layer
- **Fn+Delete**: Delete selected layer (alternative)

## Troubleshooting / 故障排除

### 问题: 键盘删除键不起作用
**解决方案**: 点击画布区域确保其获得焦点，然后再按删除键。

### Issue: Keyboard delete not working
**Solution**: Click on the canvas area to ensure it has focus, then press delete key.

### 问题: 图片位置在重新打开后改变
**解决方案**: 这个问题已在最新版本中修复。确保使用手动保存（⌘S）或等待自动保存完成。

### Issue: Image positions change after reopening
**Solution**: This issue has been fixed in the latest version. Make sure to use manual save (⌘S) or wait for auto-save to complete.

### 问题: 调整图片大小时出现跳动
**解决方案**: 这个问题已在最新版本中修复。图片现在应该平滑调整大小。

### Issue: Images jump when resizing
**Solution**: This issue has been fixed in the latest version. Images should now resize smoothly.

### 问题: 语言切换后某些文字仍是英文/中文
**解决方案**: 这个问题已在最新版本中修复。所有UI元素现在都会随语言切换而更新。

### Issue: Some text remains in English/Chinese after switching language
**Solution**: This issue has been fixed in the latest version. All UI elements now update with language switching.

## Tips & Tricks / 技巧与窍门

### 中文
1. **快速选择**: 单击图层选中，双击照片进入裁剪模式，双击文字进入编辑模式
2. **精确定位**: 使用键盘方向键微调图层位置（即将推出）
3. **批量导入**: 可以一次选择多个文件夹或图片文件导入
4. **项目备份**: 定期复制项目文件夹到外部存储设备
5. **高质量导出**: 使用"专业印刷"预设，分辨率设为300 DPI

### English
1. **Quick Selection**: Single-click to select layer, double-click photo for crop mode, double-click text to edit
2. **Precise Positioning**: Use keyboard arrow keys for fine-tuning layer position (coming soon)
3. **Batch Import**: Select multiple folders or image files at once for import
4. **Project Backup**: Regularly copy project folder to external storage
5. **High Quality Export**: Use "Professional" preset with 300 DPI resolution
