# PhotobookPro - 专业照片书制作工具

## 安装说明 / Installation

### 中文
1. 将 PhotobookPro.app 拖动到"应用程序"文件夹
2. 首次打开时，如果系统提示"无法打开"，请：
   - 打开"系统偏好设置" > "安全性与隐私"
   - 点击"仍要打开"
3. 开始创建您的照片书！

### English
1. Drag PhotobookPro.app to the Applications folder
2. On first launch, if the system shows "Cannot open":
   - Open "System Preferences" > "Security & Privacy"
   - Click "Open Anyway"
3. Start creating your photobook!

### Deutsch
1. Ziehen Sie PhotobookPro.app in den Ordner "Programme"
2. Beim ersten Start, wenn das System "Kann nicht geöffnet werden" anzeigt:
   - Öffnen Sie "Systemeinstellungen" > "Sicherheit & Datenschutz"
   - Klicken Sie auf "Trotzdem öffnen"
3. Beginnen Sie mit der Erstellung Ihres Fotobuchs!

### Français
1. Faites glisser PhotobookPro.app vers le dossier Applications
2. Au premier lancement, si le système affiche "Impossible d'ouvrir":
   - Ouvrez "Préférences Système" > "Sécurité et confidentialité"
   - Cliquez sur "Ouvrir quand même"
3. Commencez à créer votre album photo!

## 功能特点 / Features

- 📖 多种装订方式：软封面、硬封面、平装、骑马钉
- 📏 多种尺寸预设：A4、A5、A6等
- 🎨 丰富的贴纸库和自定义贴纸支持
- 🌍 多语言支持：中文、English、Deutsch、Français
- 💾 自动保存，永不丢失工作
- 📤 专业PDF导出，支持印刷出血设置

## 自定义贴纸 / Custom Stickers

应用会自动创建自定义贴纸文件夹：
`~/Library/Application Support/PhotobookPro/Stickers/`

将您的PNG/JPG图片放入此文件夹，即可在应用中使用！

The app automatically creates a custom stickers folder:
`~/Library/Application Support/PhotobookPro/Stickers/`

Place your PNG/JPG images in this folder to use them in the app!
